ESSENSROULETTE – Smartphone-Web-App

Enthalten:
- index.html
- manifest.json
- sw.js
- App-Icons

Funktionen:
- 84 Startgerichte
- 7 zufällige Gerichte pro Woche ohne Wiederholung
- Gerichte hinzufügen, bearbeiten und löschen
- Kategorien und Filter
- lokale Speicherung im Browser
- JSON-Backup exportieren/importieren
- offline-fähig nach Installation

Installation als echte PWA:
Die Dateien müssen über HTTPS bereitgestellt werden (z.B. GitHub Pages, Netlify oder eigener Webspace).
Dann die Seite am Smartphone öffnen und „Zum Home-Bildschirm“ / „App installieren“ wählen.

Zum schnellen Testen am PC:
index.html öffnen. Die Hauptfunktionen laufen auch direkt als Datei; die PWA-Installation/Offline-Cache benötigen jedoch einen Webserver.
